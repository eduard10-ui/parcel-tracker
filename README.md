# Parcel Tracker

A full-stack parcel tracking system built with PHP, MySQL, and JavaScript.

---

## What is this project?

Parcel Tracker is a simple web app that lets you track a package from the
moment it is shipped to the moment it arrives at the door. It works like the
delivery tracker you see when you shop online, but this one is built from
scratch and runs on your own computer or server.

The system has three kinds of users:

-   User   — types a tracking code to see where the parcel is right now.
-   Rider   — updates the parcel's location and delivery status as it moves.
-   Admin   — registers new parcels, manages user accounts, and can delete parcels.

---

## What can it do?

- Track a parcel by its tracking code (example: `FT-A1B2C3`)
- See the parcel's current status and current location
- View the full history of the parcel with date and time stamps
- Update the parcel through 8 delivery stages
- Update the parcel location automatically using the device's GPS
- Show the delivery route on an interactive map
- Create, read, update, and delete records (full CRUD)
